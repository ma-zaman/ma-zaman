### 🚀 About Me

Full-stack software engineer based in the Paris Region (Île-de-France), with a focus on cloud and DevOps. Currently at Capgemini Engineering (since April 2023), working on an internal POC focused on Kubernetes, DevOps and cloud topics. A computer engineering graduate from Sup Galilée, I built my experience around full-stack development, event-driven architecture, and deploying high-availability applications.  
I particularly enjoy environments where clean code, automated testing and a genuine DevOps culture make the difference. I use artificial intelligence as a productivity tool - to explore ideas faster - without ever replacing the rigor of testing and code review.
